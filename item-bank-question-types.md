# Item-bank question types

The current item bank contains 234 items: 209 sentence items and 25 paragraph tasks. This document separates the learner-facing response formats from the instructional content patterns.

## Learner-facing response formats

| Source type | Count | Runtime response mode | What the learner does |
| --- | ---: | --- | --- |
| Constructed response | 59 | Open text | Writes a repair, revision, or explanation in a text field. |
| Classification | 54 | Choice | Chooses `Complete sentence` or `Fragment`, or selects the correct classification choice. |
| Classification + explanation | 42 | Two-step classification + reason choice | Classifies the word group, then chooses the best explanation. |
| Multiple choice | 31 | Choice | Selects one option, often comparing a complete sentence with a fragment or repair. |
| Short explanation | 21 | Reason choice | Chooses the best explanation for why a sentence is complete or incomplete. |
| Classification + repair | 2 | Classification + open text | Classifies the item, then writes a repair if it is a fragment. |
| Paragraph task | 25 | Paragraph repair | Selects every fragment in a paragraph and rewrites the paragraph so each sentence is complete. |

### How these formats appear in the interface

- **Choice** uses radio-button options and supports single-answer classification or multiple-choice questions.
- **Classification + reason choice** requires both a classification and an explanation before the answer can be saved.
- **Reason choice** is a constrained explanation format used instead of requiring students to write terminology-heavy rationales.
- **Classification + repair** combines a structural judgment with a constructed revision.
- **Constructed response** is evaluated by the local open-text evaluator using the item’s rule metadata. It can return `correct`, `incorrect`, or `needsReview`.
- **Paragraph repair** checks both fragment identification and the revised paragraph, with attention to preserving meaning.

## Instructional content patterns

### Skill A — Sentence completeness

The bank includes:

- Complete-sentence and fragment classification.
- Contrast pairs that look similar but differ in whether they can stand alone.
- Explanations of why a complete sentence has a subject, main verb, and complete thought.
- Explanations of why a word group lacks an independent assertion.
- Short-sentence and length-based misconception checks.
- Punctuation traps showing that capitalization and a period do not create a complete sentence.
- Fresh classification items reserved for verification and mastery.

### Skill B — Missing essential parts

The bank includes:

- Repairs that add a missing subject.
- Repairs that add a missing predicate or finite verb.
- Independent revisions that preserve the original action or noun phrase.
- Contrasts between an `-ing` modifier and a complete finite verb.
- Explanations of missing subjects, missing predicates, and verb-like words that do not function as the main verb.
- Minimal-change repairs and embedded-modifier controls.
- Fresh evidence items reserved for verification and mastery.

### Skill C — Dependent-clause fragments

The bank includes:

- Classification of fragments beginning with subordinators such as `because`, `although`, `when`, `if`, and `unless`.
- Repairs that attach a dependent clause to a complete thought.
- Contrast items distinguishing dependent clauses from complete sentences.
- Complete sentences that contain a dependent clause, preventing the misconception that every subordinator creates a fragment.
- Relative-clause items using `who`, `which`, and `that`.
- Embedded and nested clause-complexity items.
- Production and repair tasks that preserve the relationship between ideas.

### Skill D — Phrase fragments

The bank includes:

- `-ing` or participial phrase classification and repair.
- `to + verb` infinitive-phrase classification and repair.
- Descriptive phrase classification and repair.
- Contrast items that distinguish a phrase from a complete sentence.
- Complete sentences containing participial or infinitive phrases.
- Embedded modifiers and authentic-context fragment items.

### Skill E — Contextual transfer

Skill E is represented by 25 paragraph tasks. Each paragraph asks the learner to:

1. Read the paragraph in context.
2. Select every sentence fragment.
3. Revise the paragraph so the sentences are complete.
4. Preserve the original meaning, details, and relationships between ideas.

These tasks deliberately combine the other skill patterns, including dependent clauses, participial phrases, infinitive phrases, missing predicates, and descriptive noun phrases.

## Type distribution by stage

| Stage | Classification | Classification + explanation | Classification + repair | Constructed response | Multiple choice | Short explanation | Paragraph task |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Diagnostic | 9 | 6 | 2 | 4 | 7 | 1 | 5 |
| Guided practice | 37 | 0 | 0 | 23 | 0 | 0 | 5 |
| Independent practice | 0 | 8 | 0 | 28 | 24 | 20 | 7 |
| Verification | 2 | 8 | 0 | 2 | 0 | 0 | 3 |
| Mastery assessment | 6 | 20 | 0 | 2 | 0 | 0 | 5 |

The stage distribution reinforces the learning progression: guided practice emphasizes explicit classification and repair, independent practice broadens the response demands, verification supplies fresh evidence, and mastery emphasizes protected classification-plus-reasoning items plus a smaller number of constructed and contextual tasks.
